Transformer 基础概述
背景 · 动机 · 核心优势
🧠 什么是 Transformer？ 核心概念

Transformer 是 Google 于 2017 年在论文 “Attention Is All You Need” 中提出的新型神经网络架构。它彻底摒弃了 RNN 和 CNN，完全基于 自注意力机制（Self-Attention），能够并行处理序列数据，高效捕捉长距离依赖关系。如今已成为 NLP、CV、多模态等领域的主流基础模型。

💡 简单理解：输入文本 → Encoder（编码器）→ Decoder（解码器）→ 输出结果。

🚀 为什么引入 Transformer？
  • RNN：串行计算导致训练慢，梯度消失/爆炸使得长距离依赖难以捕捉。
  • CNN：虽可并行，但需堆叠多层才能扩大感受野，建立长距离关联成本高。
  • Transformer：并行计算 + 直接建模所有位置间依赖，训练效率高且性能卓越。
⚡ Transformer 核心特点
  • ✅ 完全基于 注意力机制，无递归或卷积
  • ✅ 并行处理，充分利用 GPU 算力
  • ✅ 多头注意力，从不同子空间捕捉语义关系
  • ✅ 位置编码，注入顺序信息
  • ✅ 残差连接 + 层归一化，保障深度网络稳定训练

注意力机制详解
Self-Attention · 多头 · Scaled Dot-Product
🎯 注意力机制的本质

注意力机制可以理解为 软性的特征选择。通过 Query 和 Key 计算相似度，得到注意力权重，再对 Value 加权求和，从而聚焦于重要的信息。在 Transformer 中，自注意力使每个位置都能直接关注到所有其他位置，实现全局交互。

概念角色
Query (Q)查询向量，代表当前关注点
Key (K)键向量，用于与 Q 匹配
Value (V)值向量，根据权重提取信息

公式：Attention(Q,K,V) = softmax(QKᵀ / √dₖ) · V

🔍 Self-Attention 计算流程
  1. 输入序列每个位置通过线性变换生成 Q、K、V。
  2. Q 与所有 K 做点积，得到 n×n 注意力分数矩阵。
  3. 除以 √dₖ 进行缩放（防止梯度消失）。
  4. Softmax 归一化，得到注意力权重。
  5. 权重与 V 加权求和，得到最终输出。

💡 自注意力对输入顺序不敏感，因此需要额外位置编码。

🧩 为什么用多头注意力？
  • ✅ 捕捉 多种依赖关系（语法、语义、局部、全局）。
  • ✅ 提高 模型容量，学习更丰富的表示。
  • ✅ 增强 泛化能力，鲁棒性更强。
  • ✅ 可 并行计算，各头独立运算。

💡 单头注意力只能学习一种模式，表达能力受限。

📐 为什么需要 Scaled？（除以 √dₖ）

当 dₖ 较大时，Q·Kᵀ 的点积值方差很大，容易进入 Softmax 的 饱和区（梯度接近 0），导致梯度消失。除以 √dₖ 可以将数值拉回合理范围，保持梯度稳定，加速收敛。

📌 本质：对点积结果进行缩放，类似回归中的 log 变换，使数值分布更均匀。

⚖️ 点乘 vs 加法注意力
  • 点乘：矩阵乘法高效并行，但值可能过大 → 需缩放。
  • 加法：对长序列可能更优，但计算复杂度更高（常数因子大）。

✅ Transformer 选择点乘，因为 效率高 + 建模能力强。

🔄 为什么 Q 和 K 使用不同权重矩阵？

若 Q 和 K 共享权重或直接使用自身点积，则注意力矩阵对称，表达能力减半。使用不同权重矩阵使得 Q 和 K 可以在不同语义空间 中运作，增强了模型的灵活性和表示能力，能够捕捉更复杂的依赖关系。

核心架构组件
输入表示 · 位置编码 · Encoder-Decoder · 残差与归一化
📥 输入表示

Input Embedding + Position Encoding 相加后进入 Transformer Block。

  • 词嵌入：将 token 映射为稠密向量（维度 d_model）。
  • 位置编码：注入顺序信息（原始使用 sin/cos 函数）。

📌 为什么要乘 √d_model？—— 防止点积数值过大，保持训练稳定。

📍 位置编码（Positional Encoding）

由于 Self-Attention 对顺序不敏感，需要额外注入位置信息。原始 Transformer 使用 正弦 / 余弦 函数：

PE(pos, 2i) = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

✅ 优点：固定模式、可推广到更长序列、并行友好。
⚠️ 缺点：固定长度限制，可能需要更多数据学习利用。

🔹 其他位置编码技术：学习式位置编码（可训练参数）、相对位置编码（关注相对偏移，如 Transformer-XL）、轴向位置编码（降低参数量）等，各有优劣。

🏗️ Encoder 模块

由 N 个相同的层堆叠（原始论文 N=6），每层包含：

  • 多头自注意力（Multi-Head Self-Attention）—— 每个位置关注所有位置。
  • 前馈神经网络（Position-wise FFN）—— 两个线性变换 + ReLU/GELU 激活。
  • 每个子层后接 残差连接 + 层归一化（LayerNorm）。

📌 所有位置共享同一组参数，但每个 token 独立计算，实现并行。

🔗 残差连接（Residual Connection）
  • 输出 = LayerNorm(x + SubLayer(x))
  • ✅ 缓解 梯度消失，允许训练更深网络（上百层）。
  • ✅ 加速收敛，保持前向信息完整性（即使子层未学到有用信息，输入也能直接传递）。
  • ✅ 支持模块化堆叠，便于扩展。
📊 层归一化（LayerNorm）
  • 对 单个样本 的所有特征做归一化（均值为 0，方差为 1）。
  • ✅ 稳定训练，加速收敛。
  • ✅ 与 BN 不同：BN 在 batch 维度（依赖 batch 统计），LN 在 feature 维度，适合变长序列。

💡 Transformer 用 LN 而不是 BN，因为序列长度动态变化，BN 统计不稳定。

🔄 Encoder 与 Decoder 交互

Decoder 通过 交叉注意力 与 Encoder 交互：

  • Q：来自 Decoder 上一层的输出。
  • K、V：来自 Encoder 最后一层的输出（所有位置）。
  • Decoder 每个位置可访问 Encoder 所有位置的输出，实现信息融合。

📌 Decoder 的 Masked Self-Attention 用于防止"偷看"未来信息，保持自回归属性（生成当前词时只能依赖历史词）。

🧩 FFN（前馈神经网络）

每个 Encoder / Decoder 层中，自注意力之后接一个 FFN，结构为：

FFN(x) = max(0, xW₁ + b₁) W₂ + b₂
  • 将维度从 d_model 放大到 d_ff（通常 4 倍），再映射回。
  • 激活函数原始用 ReLU，后续变体常用 GELU（高斯误差线性单元），某些任务上表现更优。
  • 每个位置独立应用，参数不共享，增加非线性表达能力。

💡 FFN 是 Transformer 中唯一的非线性组件，对模型性能至关重要。

04
训练与优化技术
并行化 · Mask 机制 · 权重共享 · 训练技巧
⚡ 并行化体现在哪里？
  • 自注意力：所有位置同时计算注意力分数，无时序依赖。
  • 前馈网络：每个位置独立，可并行。
  • 多头注意力：各头并行计算。
  • 层间：无递归连接，可流水线并行。

⚠️ Decoder 在 推理阶段 需自回归生成，无法完全并行；
但在 训练阶段 可通过 Teacher Forcing 并行（使用真实目标序列作为输入）。

🎭 Mask 机制
  • Padding Mask：忽略填充位置，避免无效计算（在 softmax 前将 pad 位置设为 -1e9）。
  • Sequence Mask：Decoder 自注意力中，遮挡未来位置，防止信息泄露。

💡 具体操作：在 softmax 前将 mask 位置设为 -1e9，使权重趋近 0，从而忽略这些位置。

🔁 权重共享（Weight Tying）
  • Embedding 层：所有 token 共享同一套嵌入权重。
  • LM Head：输出层（Softmax 前的线性层）与 Embedding 层共享权重。

✅ 好处：减少参数量（尤其是大词表）、加速训练、提升泛化能力，使 Embedding 训练更充分。

🧪 训练技巧与超参数
  • 优化器：Adam（beta1=0.9, beta2=0.98, epsilon=1e-9）。
  • 学习率调度：预热（Warmup）—— 前 4000 步线性增长，之后按步数倒数衰减。
  • 标签平滑：将 one-hot 标签变为 (1-ε) 和 ε/(vocab_size)，避免过自信，增强泛化。
  • Dropout：训练时随机丢弃神经元（通常 0.1），测试时禁用。
  • 激活函数：原始用 ReLU，后续变体常用 GELU（在多项任务上表现更好）。
  • 梯度裁剪：防止梯度爆炸（最大范数通常设为 1.0）。

📌 典型配置：d_model=512, d_ff=2048, head=8, layers=6, dropout=0.1。

应用场景与变体模型
BERT · GPT · 多模态 · 实际落地
🧠 BERT
  • 基于 Encoder 的预训练模型（双向 Transformer）。
  • 双向自注意力，捕捉上下文信息（左右两方向）。
  • 预训练任务：MLM（掩码语言模型，随机遮盖 15% 的 token） + NSP（下一句预测）。
  • 适用场景：文本分类、命名实体识别、问答系统等理解型任务。
🤖 GPT
  • 基于 Decoder 的生成式预训练模型（单向 Transformer）。
  • 单向自注意力（从左到右），保持自回归属性。
  • 预训练：语言模型（预测下一个 token）。
  • 适用场景：文本生成、对话系统、代码生成等创作型任务。
🌐 典型应用场景
机器翻译 文本摘要 图像/视频描述 语音识别 聊天机器人 代码生成 推荐系统

📌 Transformer 已成为 NLP 领域事实上的标准架构，并逐步扩展至 CV（ViT）、多模态（CLIP、DALL-E）等领域。

⚠️ 局限性
  • 依赖 大量数据，数据稀缺时表现不佳。
  • 对 初始化 敏感，需要精心调参。
  • 可解释性 较差（黑盒模型）。
  • 处理 超长序列 时 O(n²) 复杂度，内存和计算成本高。
  • 实时 / 低延迟任务（如语音识别增量解码）可能不如 RNN。

💡 改进方向：稀疏注意力（Longformer、Reformer）、线性注意力、滑动窗口等。

🔧 其他重要变体
  • Transformer-XL：引入循环机制和相对位置编码，处理超长序列。
  • Reformer：使用局部敏感哈希（LSH）和可逆网络降低内存。
  • Longformer：采用滑动窗口 + 全局注意力，线性复杂度。
  • T5：统一的文本到文本框架，所有任务都转为生成任务。

深度解析 · 多维回答 · 助你从容应对
Q1 为什么 Transformer 使用多头注意力机制？ 显示答案

面试官想听到：多头注意力不仅是为了增加参数量，更是为了从多个子空间捕获不同种类的依赖关系，提升模型的能力和鲁棒性。

  • 子空间多样性：每个头使用不同的线性投影，学习到不同的注意力模式，例如一个头关注语法结构，另一个头关注语义相关性，第三个头关注长距离依赖。
  • 模型容量提升：增加可训练参数，使模型能够学习更复杂的表示。
  • 泛化能力增强：多头的冗余性使得即使个别头出现噪声，其他头仍能提供有效信息，提高鲁棒性。
  • 并行计算友好：各个头独立计算，可充分利用 GPU 并行能力。

💡 补充：单头注意力表达能力有限，类似集成学习中的多视角融合，多头机制提升了整体性能。

Q2 为什么 Q 和 K 使用不同的权重矩阵生成？ 显示答案

面试官想听到：使用不同权重是为了让 Q 和 K 处于不同的语义空间，从而允许模型灵活地匹配查询和键，避免对称性限制。

  • 灵活性：若 Q=K，则注意力矩阵是对称的，只能表达对称关系，限制了模型捕捉非对称依赖的能力（如语法中的主谓关系）。
  • 表示能力：不同投影矩阵使 Q 和 K 可以代表不同的语义角色，例如 Q 偏向于"问题"，K 偏向于"特征"，从而更好地实现注意力打分。
  • 梯度流动：独立的投影矩阵为反向传播提供了更多路径，有助于优化。

📌 同理，V 使用独立矩阵，使得提取的内容与匹配过程解耦，增加灵活性。

Q3 为什么需要 Scaled Dot-Product（除以 √dₖ）？ 显示答案

面试官想听到：缩放是为了控制点积值的方差，防止 Softmax 进入梯度饱和区，保证训练稳定性。

  • 方差分析：假设 Q 和 K 的每个元素独立同分布，均值为 0，方差为 1，则点积的方差为 dₖ。当 dₖ 较大时，点积值会很大，使得 Softmax 的输入处于两端（饱和区），梯度接近 0，导致梯度消失。
  • 缩放作用：除以 √dₖ 后，方差变为 1，将值拉回合理范围，保持梯度敏感度。
  • 实际效果：加速收敛，提升模型训练稳定性。

📌 这是 Transformer 中非常关键的设计细节，面试中常被追问推导过程。

Q4 为什么用 Layer Normalization 而不是 Batch Normalization？ 显示答案

面试官想听到：因为 Transformer 处理变长序列，BN 的 batch 统计不稳定，而 LN 与 batch 无关，更适合动态长度。

  • BN 的缺陷：BN 在 batch 维度计算均值和方差，当序列长度不一致时，统计量会抖动，且训练与推理时的统计量差异可能带来误差。
  • LN 的优势：LN 在特征维度（即每个样本内部）做归一化，不依赖 batch 大小，对变长序列友好，且在小 batch 时表现更稳定。
  • 训练稳定性：LN 有助于缓解内部协变量偏移，加速 Transformer 的收敛。

💡 补充：在视觉 Transformer（ViT）中，有时也会使用 BN 或混合归一化，但原始 Transformer 采用 LN 是经过验证的。

Q5 位置编码的原理是什么？有哪些变种？ 显示答案

面试官想听到：位置编码是 Transformer 融入顺序信息的关键，原始使用正余弦函数，也有可学习式、相对位置编码等变体，各有适用场景。

  • 原始正余弦编码：固定函数，无需训练，能外推至更长序列，但无法适应数据分布。
  • 可学习位置编码：将位置向量作为可训练参数，能适应任务，但无法处理超过训练长度的序列。
  • 相对位置编码：在注意力计算中直接引入相对偏移信息（如 Transformer-XL），更关注局部关系，适用于长序列。
  • 轴向位置编码：分解多个维度，降低参数量。

📌 面试中常会问到为什么不用绝对位置而用相对位置，可以结合具体模型（如 T5 使用相对偏置）展开。

Q6 残差连接在 Transformer 中的作用是什么？ 显示答案

面试官想听到：残差连接解决了深层网络训练难的问题，保证梯度有效回传，同时保留了输入信息。

  • 缓解梯度消失：通过"跳跃连接"，梯度可以直接从输出层流向浅层，避免逐层衰减。
  • 简化学习目标：每层只需学习输入与输出的残差，比直接学习完整映射更容易。
  • 信息完整性：即使某层参数未优化好，原始输入仍可通过残差直达下一层，保证前向传播的有效性。
  • 支持更深网络：使得堆叠数十层甚至上百层成为可能（如 GPT-3 有 96 层）。

📌 残差结构是深度学习中的通用技巧，Transformer 中与 LayerNorm 配合使用，构成 Post-Norm 或 Pre-Norm 结构（Pre-Norm 更常见于现代变体）。

Q7 Decoder 的 Masked Self-Attention 为什么需要序列掩码？ 显示答案

面试官想听到：序列掩码是维持自回归属性（因果性）的必要手段，防止模型在训练时"看到"未来信息，导致推理时无法使用。

  • 自回归要求：生成第 t 个 token 时，只能依赖前 t-1 个 token，不能利用 t 之后的 token。
  • 训练时：虽然已知完整目标序列，但必须通过掩码模拟推理时的条件，确保模型学会基于历史信息预测。
  • 实现方式：在计算注意力分数后，将未来位置的分数设为 -∞（或极负数），经过 Softmax 后权重为 0。
  • 重要性：若不掩码，模型会作弊，导致测试时性能严重下降（因为推理时无法获取未来信息）。

💡 这也是 Decoder 比 Encoder 多一个 Masked 多头注意力的原因。

Q8 Transformer 的并行化体现在哪些方面？Decoder 能完全并行吗？ 显示答案

面试官想听到：并行化是 Transformer 相较于 RNN 的核心优势，但 Decoder 推理阶段受自回归限制，无法完全并行。

  • 训练阶段并行：自注意力和 FFN 均可并行计算所有位置，多头各头并行，层间无时序依赖，因此训练非常高效。
  • Decoder 训练并行：通过 Teacher Forcing 使用真实目标序列作为输入，所有位置同时参与计算，因此训练时可并行。
  • Decoder 推理串行：生成是逐步的（自回归），当前步依赖上一步的输出，因此无法完全并行，只能通过缓存（KV Cache）加速。

📌 面试中可能会追问"如何提升推理并行度"，可以提到非自回归生成、并行解码等方向。

Q9 BERT 和 GPT 在架构与设计上有何本质区别？ 显示答案

面试官想听到：两者分别是 Encoder-only 和 Decoder-only 的代表，方向（双向 vs 单向）和预训练任务不同，决定了它们擅长的任务类型。

  • 架构：BERT 使用 Transformer Encoder（双向自注意力），GPT 使用 Transformer Decoder（单向掩码自注意力）。
  • 预训练任务：BERT 采用 MLM（掩码语言模型）+ NSP（下一句预测），GPT 采用语言模型（预测下一个 token）。
  • 适用任务：BERT 擅长理解类任务（分类、命名实体识别、问答），GPT 擅长生成类任务（文本生成、对话、代码生成）。
  • 训练效率：BERT 双向能看到上下文，适合深层语义理解；GPT 单向自回归，适合生成。

💡 现在的趋势是 Decoder-only 架构（如 GPT）也能通过 prompt 方式完成理解任务，但两者设计初衷不同。

Q10 FFN 在 Transformer 中的作用，以及为什么采用两层的设计？ 显示答案

面试官想听到：FFN 引入非线性，增强模型表达能力，两层设计平衡了参数量和计算效率。

  • 非线性引入：自注意力是线性变换（加权求和），必须引入非线性层才能拟合复杂函数。
  • 两层结构：先升维（d_model → d_ff，通常 4 倍），再降维（d_ff → d_model），中间用 ReLU/GELU 激活。这种设计在增加非线性同时控制了参数量（相对于三层而言）。
  • 位置独立：FFN 对每个位置独立应用，参数共享，有助于学习位置特定的特征。
  • 激活函数选择：ReLU 简单高效，GELU 更平滑，部分任务上性能更优。

📌 面试中可能追问"能否用其他结构代替 FFN？"，可以讨论 MoE（混合专家）等变体。

Q11 如何处理输入序列中的 Padding ？ 显示答案

面试官想听到：使用 Padding Mask 让模型忽略填充位置，避免它们影响注意力计算和 loss。

  • 构建 mask：在注意力分数矩阵中，将对应填充 token 的位置设为 -∞（或 -1e9）。
  • 作用时机：在 Softmax 之前应用，使得填充位置的权重变为 0，从而不会参与加权求和。
  • Loss 计算：在计算损失时，也需要忽略填充位置（通常通过 ignore_index 实现）。
  • 重要性：如果不处理，填充 token 会引入噪声，影响模型性能。
Q12 Transformer 的局限性有哪些？如何改进？ 显示答案

面试官想听到：Transformer 并非万能，存在计算复杂度高、数据需求大、可解释性差等不足，业界已有多种改进方案。

  • 计算复杂度过高：O(n²) 的自注意力限制了长序列处理。改进：稀疏注意力（Longformer）、线性注意力（Linformer）、局部注意力（Swin Transformer）。
  • 数据需求大：小数据集上容易过拟合。改进：预训练 + 微调，数据增强，正则化（Dropout、权重衰减）。
  • 可解释性差：注意力权重未必能直接解释决策。改进：注意力可视化、Grad-CAM 等工具。
  • 对超参数敏感：需要仔细调参。改进：使用自适应优化器（AdamW）和合理的学习率调度。
  • 推理速度：自回归生成慢。改进：非自回归生成、知识蒸馏、量化。

💡 面试中如果提到改进，可以结合具体模型（如 Reformer、Performer）展开。

Q13 为什么需要学习率预热（Warmup）？ 显示答案

面试官想听到：预热是为了在训练初期稳定梯度，避免因初始学习率过大导致参数震荡。

  • 初期不稳定：模型参数随机初始化，梯度方差大，若直接用大学习率，容易导致 loss 爆炸或收敛到局部最优。
  • 预热策略：线性增加学习率（如从 0 到目标值，通常 4000 步），使模型平稳起步。
  • 后续衰减：预热后，学习率按指数或倒数衰减，帮助模型精细调整。
  • 实验证明：Transformer 原始论文采用预热，后续大型模型（如 GPT-3）也沿用，证明其有效性。
Q14 Weight Tying（权重绑定）是什么？有什么好处？ 显示答案

面试官想听到：权重绑定是一种参数共享策略，可减少参数量，提升训练效率和泛化能力。

  • 定义：将 Embedding 层的权重矩阵与 Decoder 输出层（Softmax 前的线性层）的权重共享。
  • 原理：两者维度均为 vocab_size × d_model，在数学上可共享。
  • 好处：① 减少参数量（大词表时节省明显）；② 加速训练，因为 Embedding 和输出层同步更新；③ 提升泛化能力，使词向量学习更充分。
  • 典型应用：GPT、Transformer 原始模型均采用了权重绑定。

📌 面试中可能追问"是否所有情况都适用？"，可以讨论当 Encoder 和 Decoder 词表不同时无法共享。

Q15 如何缓解 Transformer 的过拟合？ 显示答案

面试官想听到：过拟合是深度模型常见问题，Transformer 可以通过多种正则化手段有效缓解。

  • Dropout：在注意力权重、FFN 和 Embedding 后应用，随机丢弃神经元（通常 0.1~0.3）。
  • 权重衰减（L2 正则化）：限制参数幅度，防止极端权重。
  • 标签平滑：将 one-hot 标签软化，避免模型过于自信，提升泛化。
  • 早停：监控验证集性能，停止训练以防过拟合。
  • 数据增强：回译、随机替换等，扩充训练数据。
  • 使用预训练模型：冻结底层或微调，利用大规模预训练学到的通用特征。

💡 在实际调优中，通常会组合多种策略，并通过交叉验证选择最佳组合。
