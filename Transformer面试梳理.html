Transformer 基础概述
从零认识 Transformer · 为什么诞生 · 核心特点
🧠 什么是 Transformer？ 核心概念

Transformer 是 Google 于 2017 年提出的一种新型神经网络架构，核心在于 自注意力机制（Self-Attention）。它能够并行处理输入序列，高效捕捉长距离依赖关系，广泛应用于 NLP、CV 等多模态任务。

💡 简单理解：输入文本 → Encoder（编码器）→ Decoder（解码器）→ 输出结果。

🚀 为什么引入 Transformer？
  • RNN：串行计算，训练慢，长距离依赖难以捕捉。
  • CNN：并行计算好，但建立长距离关联需要很深的网络。
  • Transformer：并行计算 + 精确捕捉长距离依赖，一举两得。
⚡ Transformer 核心特点
  • ✅ 完全基于 注意力机制，无 RNN/CNN
  • ✅ 并行处理，训练效率极高
  • ✅ 多头注意力，捕捉多种语义关系
  • ✅ 位置编码，注入序列顺序信息
  • ✅ 残差连接 + 层归一化，训练稳定
📊 与 RNN / LSTM 的对比
维度RNN / LSTMTransformer
计算方式串行（逐词处理）并行
长距离依赖梯度消失/爆炸，难以捕捉直接建模（自注意力）
训练速度慢快（GPU 友好）
位置信息天然包含（时序）需 位置编码

注意力机制详解
Self-Attention · 多头注意力 · Scaled Dot-Product
🎯 注意力机制的本质

注意力机制可以理解为 软性的特征选择。通过 Query 和 Key 计算相似度，得到注意力权重，再对 Value 加权求和，从而聚焦于重要的信息。

概念角色
Query (Q)查询向量，代表当前关注点
Key (K)键向量，用于与 Q 匹配
Value (V)值向量，根据权重提取信息

公式：Attention(Q,K,V) = softmax(QKᵀ / √dₖ) · V

🔍 Self-Attention 怎么算？
  1. 输入序列每个位置生成 Q、K、V
  2. Q 与所有 K 做点积，得到 n×n 注意力分数矩阵
  3. 除以 √dₖ 进行缩放
  4. Softmax 归一化，得到注意力权重
  5. 权重与 V 加权求和，得到输出

💡 自注意力对输入顺序不敏感，因此需要位置编码。

🧩 为什么用多头注意力？
  • ✅ 捕捉 多种依赖关系（语法、语义等）
  • ✅ 提高 模型容量 和表达能力
  • ✅ 更好的 泛化能力
  • ✅ 可 并行计算，效率高

💡 单头注意力表达能力受限，多头能从不同子空间学习。

📐 为什么需要 Scaled？（除以 √dₖ）

当 dₖ 较大时，Q·Kᵀ 的点积值方差很大，容易进入 Softmax 的 饱和区，导致梯度消失。除以 √dₖ 可以将数值拉回合理范围，保持梯度稳定，加速收敛。

📌 类比：回归问题中对标签做 log 变换，让数值分布更均匀。

⚖️ 点乘 vs 加法注意力
  • 点乘：矩阵乘法高效并行，但值可能过大 → 需缩放。
  • 加法：对长序列可能更优，但计算复杂度更高（常数因子大）。

✅ Transformer 选择点乘，因为 效率高 + 建模能力强。

03
核心架构组件
输入表示 · 位置编码 · Encoder-Decoder · 残差与归一化
📥 输入表示

Input Embedding + Position Encoding 相加后进入 Transformer Block。

  • 词嵌入：将 token 映射为稠密向量
  • 位置编码：注入顺序信息（sin/cos 函数）

📌 为什么要乘 √d_model？—— 防止点积数值过大，保持训练稳定。

📍 位置编码（Positional Encoding）

由于 Self-Attention 对顺序不敏感，需要额外注入位置信息。原始 Transformer 使用 正弦 / 余弦 函数：

PE(pos, 2i) = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

✅ 优点：固定模式、可推广到更长序列、并行友好。
⚠️ 缺点：固定长度限制，可能需要更多数据学习利用。

🏗️ Encoder 模块

由 N 个相同的层堆叠，每层包含：

  • 多头自注意力（Multi-Head Self-Attention）
  • 前馈神经网络（Position-wise FFN）
  • 每个子层后接 残差连接 + 层归一化
🔗 残差连接（Residual Connection）
  • 输出 = LayerNorm(x + SubLayer(x))
  • ✅ 缓解 梯度消失，训练更深网络
  • ✅ 加速收敛，保持前向信息完整性
📊 层归一化（LayerNorm）
  • 对 单个样本 的所有特征做归一化（均值为 0，方差为 1）
  • ✅ 稳定训练，加速收敛
  • ✅ 与 BN 不同：BN 在 batch 维度，LN 在 feature 维度

💡 Transformer 用 LN 而不是 BN，因为序列长度动态变化，BN 不稳定。

🔄 Encoder 与 Decoder 交互

Decoder 通过 交叉注意力 与 Encoder 交互：

  • Q：来自 Decoder 上一层的输出
  • K、V：来自 Encoder 的输出
  • Decoder 每个位置可访问 Encoder 所有位置的输出

📌 Decoder 的 Masked Self-Attention 用于防止"偷看"未来信息，保持自回归属性。

04
训练与优化技术
并行化 · Mask 机制 · 权重共享 · 训练技巧
⚡ 并行化体现在哪里？
  • 自注意力：所有位置的注意力分数可并行计算
  • 前馈网络：每个位置独立，可并行
  • 多头注意力：各头并行计算
  • 层间：无递归依赖，可并行

⚠️ Decoder 在 推理阶段 需自回归生成，无法完全并行；
但在 训练阶段 可通过 Teacher Forcing 并行。

🎭 Mask 机制
  • Padding Mask：忽略填充位置，避免无效计算
  • Sequence Mask：Decoder 自注意力中，遮挡未来位置，防止信息泄露

💡 具体操作：在 softmax 前将 mask 位置设为 -1e9，使权重趋近 0。

🔁 权重共享
  • Embedding 层：所有 token 共享同一套嵌入权重
  • LM Head：输出层与 Embedding 层共享权重（Weight Tying）

✅ 好处：减少参数量、加速训练、更好的泛化能力。

🧪 训练技巧
  • 优化器：Adam（结合动量与 RMSProp）
  • 学习率调度：预热（Warmup）→ 逐渐衰减
  • 标签平滑：避免过于自信，增强泛化
  • Dropout：训练时随机丢弃神经元，测试时禁用
  • GELU 激活：ReLU 的平滑变体，部分任务效果更好

应用场景与变体模型
BERT · GPT · 多模态 · 实际落地
🧠 BERT
  • 基于 Encoder 的预训练模型
  • 双向自注意力，捕捉上下文信息
  • 预训练任务：MLM（掩码语言模型）+ NSP（下一句预测）
🤖 GPT
  • 基于 Decoder 的生成式模型
  • 单向自注意力（从左到右）
  • 预训练 → 微调，擅长文本生成
🌐 典型应用场景
机器翻译 文本摘要 图像/视频描述 语音识别 聊天机器人 代码生成

📌 Transformer 已成为 NLP 领域事实上的标准架构，并逐步扩展至 CV、多模态等领域。

⚠️ 局限性
  • 依赖 大量数据，数据稀缺时表现不佳
  • 对 初始化 敏感
  • 可解释性 较差（黑盒模型）
  • 处理 超长序列 时计算成本高（O(n²)）
  • 实时 / 低延迟任务可能不如 RNN

🎯 面试高频考点
精选核心面试题 · 点击切换答案 · 自测备战
Q1 为什么 Transformer 使用多头注意力机制？ 显示答案

核心原因：多头注意力允许模型在 不同子空间 中独立学习多种依赖关系，提高表达能力和泛化能力。

  • ✅ 捕捉 多种依赖（语法、语义、局部、全局）
  • ✅ 增加 模型容量，学习更丰富表示
  • ✅ 提升 泛化能力，鲁棒性更强
  • ✅ 可 并行计算，效率高

💡 单头注意力只能学习一种模式，表达能力有限。

Q2 为什么 Q 和 K 使用不同的权重矩阵生成？ 显示答案

核心原因：提供更大的 灵活性和表示能力，让 Q 和 K 在不同语义空间运作。

  • ✅ 灵活性：不同权重可捕捉不同依赖模式
  • ✅ 表示能力：Q 和 K 可在不同语义空间表达
  • ✅ 区分角色：Q 代表查询，K 代表被匹配的键，角色不同

📌 若 Q=K，则注意力矩阵对称，表达能力减半。

Q3 为什么需要 Scaled Dot-Product？（除以 √dₖ） 显示答案

核心原因：防止点积值过大，避免 Softmax 进入 饱和区，导致梯度消失。

  • ✅ 当 dₖ 较大时，Q·Kᵀ 的方差很大
  • ✅ 除以 √dₖ 使数值分布更均匀
  • ✅ 保持 梯度稳定，加速模型收敛

📌 本质：将点积结果缩放到合理范围，类似 log 变换。

Q4 为什么用 Layer Normalization 而不是 Batch Normalization？ 显示答案

核心原因：Transformer 输入序列长度 动态变化，BN 在 batch 维度统计不稳定。

  • ✅ LN 在 特征维度 归一化，与 batch 无关
  • ✅ BN 在 batch 维度，依赖 batch 统计量，序列长度变化时不稳定
  • ✅ LN 对 单个样本 做归一化，适合变长序列

💡 简单说：LN 关注"一句话内"的分布，BN 关注"一批话之间"的分布。

Q5 位置编码的原理是什么？为什么需要它？ 显示答案

核心原因：Self-Attention 本身 不包含顺序信息，需要额外注入位置信息。

  • ✅ 使用 正弦 / 余弦 函数生成固定位置编码
  • ✅ 公式：PE(pos, 2i) = sin(pos / 10000^(2i/d))
  • ✅ 优点：固定、可推广到更长序列、并行友好

📌 其他位置编码技术：学习式、相对位置编码、Transformer-XL 等。

Q6 残差结构在 Transformer 中的作用是什么？ 显示答案
  • ✅ 缓解 梯度消失，使深层网络可训练
  • ✅ 加速 收敛，改善梯度流通
  • ✅ 保持 前向信息完整性，即使子层未学到有用信息，输入也能直接传递
  • ✅ 支持 模块化设计，便于堆叠更多层

📌 公式：Output = LayerNorm(x + SubLayer(x))

Q7 Decoder 的 Masked Self-Attention 为什么需要序列掩码？ 显示答案

核心原因：保持 自回归属性，生成当前词时只能依赖之前的词，不能"偷看"未来。

  • ✅ 训练时：通过 Teacher Forcing 已知完整目标序列，但需 mask 未来位置
  • ✅ 推理时：自左向右逐词生成，天然无法看到未来
  • ✅ 操作：在 softmax 前将未来位置设为 -1e9，使权重为 0

💡 如果不用 mask，模型会学习到"使用未来信息"的错误依赖。

Q8 Transformer 的并行化体现在哪些方面？Decoder 能并行吗？ 显示答案

并行化体现：

  • ✅ 自注意力：所有位置同时计算
  • ✅ 前馈网络：每个位置独立
  • ✅ 多头注意力：各头并行
  • ✅ 层间：无递归依赖

Decoder 并行化：

  • ✅ 训练阶段：可通过 Teacher Forcing 并行（已知目标序列）
  • ⚠️ 推理阶段：需自回归生成，无法完全并行
Q9 BERT 和 GPT 在架构上有什么本质区别？ 显示答案
  • BERT：基于 Encoder，双向 自注意力，擅长理解任务（分类、问答等）
  • GPT：基于 Decoder，单向 自注意力（从左到右），擅长生成任务（写作、对话等）
  • BERT 预训练：MLM + NSP；GPT 预训练：语言模型（自回归）

💡 两者都是 Transformer 的衍生，但设计目标不同。

Q10 FFN（前馈神经网络）在 Transformer 中的作用？ 显示答案

核心作用：为模型引入 非线性变换，增强表达能力。

  • ✅ 结构：Linear → ReLU/GELU → Dropout → Linear
  • ✅ 每个位置独立应用，参数不共享
  • ✅ 将维度从 d_model 放大到 d_ff（通常 4 倍），再映射回
  • ✅ 激活函数：原始用 ReLU，后续变体用 GELU

📌 FFN 是 Transformer 中唯一非线性的部分，至关重要。

Q11 如何处理输入序列中的 Padding ？ 显示答案

核心方法：使用 Padding Mask 忽略填充位置。

  • ✅ 构建 mask 矩阵：填充位置设为 -1e9，有效位置为 0
  • ✅ 将 mask 加到注意力分数上（softmax 之前）
  • ✅ 经过 softmax 后，填充位置的权重趋近于 0
  • ✅ 确保模型 不关注 无效的填充 token
Q12 Transformer 的局限性有哪些？ 显示答案
  • ⚠️ 依赖 大量数据，小数据集上表现不佳
  • ⚠️ 对 初始化 敏感，需要 careful tuning
  • ⚠️ 可解释性 差，难以调试
  • ⚠️ 处理 超长序列 时 O(n²) 复杂度，内存和计算成本高
  • ⚠️ 不适用于 低延迟实时任务（如语音识别增量解码）

📌 改进方向：稀疏注意力（Longformer、Reformer）、线性注意力等。

Q13 为什么 Transformer 的训练需要学习率预热（Warmup）？ 显示答案

核心原因：模型初期参数随机，梯度方向不稳定，大学习率会导致 训练不稳定。

  • ✅ 预热阶段：学习率从 0 逐渐增加到目标值
  • ✅ 帮助模型 平稳起步，避免震荡
  • ✅ 预热后逐步衰减，精细调整

📌 典型配置：前 4000 步 warmup，之后 decay。

Q14 Weight Tying（权重绑定）是什么？有什么好处？ 显示答案

定义：将 Embedding 层的权重与 Decoder 输出层（Softmax 前线性层）的权重 共享。

  • ✅ 减少参数量，压缩模型大小
  • ✅ 使 Embedding 训练更充分，缓解稀疏更新
  • ✅ 提升 泛化能力

📌 因为 Embedding 和输出层 shape 相同（vocab_size × d_model），天然可共享。

Q15 如何缓解 Transformer 的过拟合？ 显示答案
  • ✅ Dropout：训练时随机丢弃神经元（测试时禁用）
  • ✅ 权重衰减（L2 正则化）
  • ✅ 标签平滑：避免模型过于自信
  • ✅ 早停：验证集性能不再提升时停止训练
  • ✅ 数据增强：扩充训练集
  • ✅ 使用 更大的数据集 或 预训练模型
